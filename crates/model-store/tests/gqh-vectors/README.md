GQH decode vectors generated with geoquant.formats.gqh on
feat/custom-format-family (encode3/encode/encode_c). Each wire.bin is
the standalone GQH payload: 5-byte header plus superblocks for gqh3 and
gqh2_h, superblocks only for gqh2_c. decode.f32 is the reference
reconstruction, float32 little-endian, row-major.
